Text to File

A lightweight browser-based tool for converting text into downloadable files.

Features

- 📝 Simple text editor
- 📥 Download text as a file
- ⚡ Fast and lightweight
- 📱 Responsive design
- 🔒 Runs entirely in the browser
- 🎨 Clean and minimal UI

Built With

- HTML
- CSS
- JavaScript

Project Structure

Text-to-File/
├── index.html
├── style.css
└── script.js
